# salla-watch

بوت يراقب منتج **جوز حمام محشي** من متجر "أصل الحمام" على سلة، ويرسل لك رسالة تيليجرام أول ما يتوفر.

## كيف يشتغل
- يراقب كل يوم من 7 المساء لين 2 الفجر (توقيت السعودية). التشغيل كل دقيقة من cron-job.org، وGitHub Actions يشغّله احتياطياً كل 5 دقايق في نفس الوقت. خارج هالوقت ما يفحص.
- السكربت يقرأ 3 إشارات من صفحة المنتج: نص زر السلة (`salla-add-product-button`)، و meta `product:availability`، و schema.org availability. إذا أي وحدة تغيّرت عن قيمة "نفدت الكمية" (حتى لو لقيمة جديدة ما نعرفها) (مثلاً الزر ما عاد مكتوب فيه "نفدت الكمية") يرسل التنبيه.
- ما يرسل شي وهو غير متوفر. أول ما يتوفر يرسل التنبيه 3 مرات (بين كل وحدة 10 ثواني) مع الرابط.
- إذا صار متوفر: يرسل التنبيه 3 مرات، وما يكرره وهو لسا متوفر. إذا نفد ورجع توفر، ينبهك من جديد. ما يرسل أي رسالة ثانية غير تنبيه التوفر. البوت ما يوقف نفسه.
- إذا المتجر أخفى المنتج (سلة تحوّل الرابط لصفحة المتجر)، يعتبره غير متوفر بدون خطأ، ويرجع يفحص عادي لما يرجع المنتج.
- الأخطاء المؤقتة (حظر عابر 403، انقطاع، صفحة غريبة) يعيد فيها المحاولة 3 مرات، وما يفشل الـ run ويجيك إيميل إلا إذا تكرر الخطأ 15 فحص ورا بعض.

## الإعداد
1. افتح @BotFather في تيليجرام ← `/newbot` ← اختر اسم ويوزر ينتهي بـ `bot` ← انسخ التوكن.
2. أرسل أي رسالة للبوت حقك، بعدين افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` وخذ الرقم اللي في `"chat":{"id": ...}`.
3. في الـ repo: Settings ← Secrets and variables ← Actions ← New repository secret:
   - `TELEGRAM_TOKEN`
   - `TELEGRAM_CHAT_ID` (لأكثر من شخص افصل بين الأرقام بفاصلة، مثل `111,222`)
4. Actions ← Salla stock watch ← Run workflow عشان تجربه يدوي.

## إذا توقف
Actions ← Salla stock watch ← Enable workflow، وتأكد إن المهمة في cron-job.org مفعّلة.
